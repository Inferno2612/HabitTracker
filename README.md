# Трекер привычек — конструктор листов для печати

Офлайн-приложение для создания и печати трекеров привычек. Это один HTML-файл: без установки, без интернета и без зависимостей.

## Запуск

Откройте `Трекеры.html` в браузере. Лучше всего печатают Chrome, Edge и Яндекс Браузер.

## Возможности

- **Живое превью.** Листы размечены в миллиметрах, на бумаге получается ровно то, что на экране.
- **Автоподгонка под лист.** Ориентация выбирается сама. Длинные периоды и большие списки привычек автоматически делятся на несколько листов: по месяцам, неделям или поровну.
- **Три макета:** привычки в строках, дни в строках, карточки-календари.
- **Два режима:** с датами (любой период до 400 дней, готовые пресеты) или без дат (заданное число отметок).
- **10 форм отметок** в векторе. Внутри отметки можно вывести число или порядковый номер.
- **Режимы печати:** цветной, экономия краски, чёрно-белый.
- **Настройка оформления:**
  - любой цвет;
  - 5 шрифтов;
  - размер текста;
  - толщина линий;
  - форматы A3, A4, A5 и Letter;
  - поля.
- **Дополнительные элементы:** дни недели, выделение выходных, графа «Итого», нумерация, место для заметок, пустые строки для записи от руки.
- **Шаблоны.** Настройки сохраняются автоматически, их можно экспортировать в JSON и импортировать обратно.

## Печать

Нажмите **«Печать / PDF»** и выберите принтер или «Сохранить как PDF». Размер и ориентация листа подставятся автоматически. В окне печати оставьте:

- масштаб **100% / «По умолчанию»**;
- поля **«По умолчанию»**.
